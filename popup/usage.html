Usage Instructions

How to Use Prompt Saver

Prompt Saver allows you to save and quickly reuse prompts in any text input field across the web.

Saving a Prompt

There are two ways to save a prompt:

Method 1: Using the Popup

  1. Click the extension icon to open the popup
  2. Enter a title for your prompt
  3. Enter the prompt content
  4. Click "Save Prompt"

Method 2: Using a Command in Any Input Field

Type in any input field:

#prompt-save:name followed by your prompt text

Example: #prompt-save:greeting Hello! How can I help you today?

Using a Saved Prompt

To insert a saved prompt into any input field:

Quick Insert

Type # followed by your prompt name, then press Enter or Tab to insert it. As you type, a filtered dropdown of matching prompts will appear:

#name

Example: #greeting will show your saved greeting prompt in the dropdown; press Enter or Tab to insert it

Browse and Select

  1. Type # in any input field
  2. A dropdown will appear showing all available prompts
  3. Use ↑ ↓ arrow keys to navigate
  4. Press Enter or Tab to select
  5. Press Esc to cancel

Managing Prompts

  • View all prompts: Open the extension popup to see all saved prompts
  • Update a prompt: Save a prompt with the same name to update its content
  • Delete a prompt: Click the × button next to a prompt in the popup

Site Settings

You can enable or disable the extension for specific websites:

  • Open the extension popup while on the website
  • Use the toggle switch at the top to enable/disable
  • When disabled, the extension won't work on that site

💡 Tips

  • Prompt names can contain letters, numbers, underscores, hyphens, spaces, slashes, colons, and periods
  • Start typing # to see all available prompts instantly
  • Keep prompt names short and memorable for quick access
  • Use descriptive names to easily identify your prompts
